# 《龙冠枯荣》创作工作流

这个 `docs` 文件夹是一座独立的 Obsidian 内容库。网站的颜色、排版、组件和自动生成逻辑都位于仓库外层的 `overrides` 与 `tools`，日常创作不需要接触它们。

## 新建公开条目

1. 在 `zh` 下进入最符合内容类型的文件夹，例如人物放在 `zh/星辰微光`，地理放在 `zh/山河地理`。
2. 新建与条目同名的 Markdown 文件。
3. 打开命令面板，执行“模板：插入模板”，选择对应的公开条目模板。
4. 填写 `description`。它必须是一句能让陌生读者理解条目价值的话。
5. 正文照常使用 Markdown；条目之间使用 Obsidian 自动生成的相对 Markdown 链接。
6. 在 `related` 中填写需要展示在文末的条目，例如 `"[[长域]]"`。不需要手写相关条目卡片。

新条目位于 `zh` 后会自动进入网站导航与条目索引，不再修改 `mkdocs.yml` 或索引页。

## 新建私人草稿

在 `weiser` 下新建文件并插入“私人草稿”模板。网站只构建 `zh`，因此 `weiser` 不会被公开。

## 内容检查

打开 `内容工作台.base`，可以查看公开内容、缺少简介、缺少关联、私人草稿和最近修改。发布前回到仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m mkdocs build --strict --clean --config-file mkdocs.yml
```

构建失败时先看终端指出的文件。最常见的问题是缺少 `description`、`related` 指向不存在的条目，或 Markdown 链接路径错误。
