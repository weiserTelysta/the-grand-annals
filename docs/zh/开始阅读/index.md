# 开始阅读

这不是一份要求你从头背诵的设定集。你可以沿着一条短小的阅读路径认识世界，也可以直接从最感兴趣的人物、地域或法则开始。

## 建议阅读顺序

1. **[先认识这个世界](../世界总览/index.md)**
   了解作品定位、核心气质与世界的总体框架。
2. **[再理解世界的基础](../世界总览/世界基础.md)**
   从最基本的概念进入这片天地。
3. **[最后观察世界如何运转](../法则设定/魔法体系/index.md)**
   从魔法体系理解文明对世界的认识。

## 按兴趣探索

- **[世界与法则](../法则设定/index.md)**
  认识世界结构、底层秩序与魔法体系。
- **[山河与诸邦](../山河地理/index.md)**
  循地理进入地域、国家、城市与文明。
- **[历史与纪元](../历史纪元/index.md)**
  沿时代变迁理解秩序的兴替与余波。
- **[众生与人物](../星辰微光/index.md)**
  从个体命运看见宏大历史中的微光。

## 查找具体条目

使用页面顶部的搜索，或前往[条目索引](../索引/index.md)浏览当前已经公开的内容。索引负责帮助查找；首页与分类页则为初次阅读者挑选更合适的入口。
