# 龙冠枯荣
> 如你我所见，这个世界便从这里开始了。她可能是一个漫漫无期、从不休止的项目，也可能是一个走走停停、磕磕碰碰的项目。我们都知道，她一定会有个终点，过程如何，付出如何，几多犹豫，几多辛苦，我仍然希望，给她一个理想之中的正确的、令人满意的结果。
## 项目概述
**《龙冠枯荣》** 是一个以史诗奇幻、严肃叙事与架空文明史为核心的世界观构建项目。，现以 MkDocs 搭建并维护于 annals.telysta.com。

在这里，我想尽力褪去传统史诗中所常常伴随的沉重与阴云，将一个前景永远是大地在呼吸，生灵在生息的广袤世界纤毫毕现地呈现给你。

从山川市井到百族众神，我力求从不繁冗的细节出发，去讲述一方方天地、一处处文明、一位位角色，我希望你在这阳光与微风所拂过广域之上，感受这片土地庄严深沉的底色，捋顺隳颓崩解，又在废墟中焕发新芽的兴衰更迭。

愿你在这些不故弄玄虚，不矫揉造作的文字中，感受并分享这一份写给每一位旅人的史诗。
### 创作初衷与背景
本项目脱胎于一次创作理念的分歧。在过去的共创经历中，当旧有的设定逐渐滑落向无穷的繁冗主义和脱离目标的自娱自乐的窠臼，人与人曾经的合力也逐渐相互拖累。意见的分歧可以弥合，但放弃基本的创作原则绝不可接受，我最终选择坚守最初所共同认可的底层逻辑。

因此，《龙冠枯荣》现在成为了一个纯粹的、属于我个人的精神锚点，它是对过去向随意和繁冗妥协的一次彻底清洗，也是对曾经理想与目标的一次三思后的重构。
