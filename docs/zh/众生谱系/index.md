# 众生谱系
## 起源
在首观之后，世界上的森罗万象得以在织域的基础上显现，但彼时的世界尚未孕育出生命，秩序也尚未被锚定。山川隆起，大河奔流，野火肆虐，飓风浩荡，这些显相能够存在，但是却并不被认知，能够变化，却不能被记忆。

直到圣树自织域中诞生，它是最源初的生命原点，从此，世间有了生命这一概念；从此，世界的混沌有了边界、无序有了方向，不可言说之物能够被认知、被确认、被区分。

生命的概念与圣树相伴而生，它稳定了肉体的生老，承载了灵魂最初的锚定，使得百族众生的出现不再是短暂的偶然，而成为了世代延续的谱系。
## 圣树与苗裔
圣树自织域稳定之后的经纬上诞生，它是经纬之上最先出现的生命原点。它的根须深入经纬，它的树冠直触苍穹，它是生命这一概念在现实中的显相。

圣树在每个花纪孕育出真花，第一个真花纪时，祖龙自树冠而生。

它在世界稳定后振翮而起，离开圣树的荫蔽，向大陆、山脉、海洋与天空而去。他们是强大而美丽的种族，他们的血肉本身便可拨动经纬，能够凭借本能改造着栖息的环境。他们另热量奔涌，令狂风臣服，最先霸占并享有了整个世界。

祖龙便是百族的先祖，真龙、海兽，那些如今仍然强大无比的种族，皆是它的后裔，他们享有了力量，他们的天赋另大部分文明的种族欣羡。

古灵便在第二个真花纪开始时诞生。他们是文明与智慧的种族，因而在圣树周围繁衍、生息，守护着圣树的根系，照料其枝叶，并从中窥探到织域的奥秘。

后世中，长灵，人类，疍灵等诸多文明，皆可以追溯到这一真花的谱系，他们不一定拥有古灵的长寿与敏锐，却一起继承了这一谱系对秩序、记忆的传承以及互相之间的亲和。

	圣树是整个生命的历史开始的起点，也是一切有意义、可认知的世界开始的肇始。此后，生命在龙与花的谱系交错中演进，织域的显相所组成的世界，也随着生命锚点的复制与扩张臻于稳定。
