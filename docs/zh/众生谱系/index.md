# 众生谱系
## 起源
在首观之后，世界上的森罗万象才得以在织域的基础上显现，但彼时的世界尚未孕育出生命，秩序也尚未被锚定。山川隆起，大河奔流，野火肆虐，飓风浩荡，这些显相能够存在，但是却并不被认知，直到圣树自织域中诞生，他是最源初的生命原点，从此，世间有了生命这一概念；从此，世界的混沌有了边界、无序有了方向，不可言说之物能够被认知、被确认、被区分。
## 



在首观之后，织域方才形成，世界的万象森罗得以显现，但彼时尚未孕育生命，亦未锚定秩序。

山川隆起，河流奔涌，火焰肆虐，风飓浩荡。但这些显相只是世界的形质，它们能够存在，却不能记忆；能够变化，却不能自知。

直到圣树自织域之上诞生，作为织域上最先诞生的生命原点，从此世界才有了生命的概念。
