# 魔法体系导言
>“魔法的局限性比其能力本身更有趣。”
>——布兰登·桑德森
## 序言
在《龙冠枯荣》之中，魔法不是神迹，也不是不可知、不可测的神秘力量，而是智慧种族在探索和观察世界时，逐步建立的一套解释并运用世界规律的认知系统。

这个世界并非由绝对存在的物质组合而成，而是由织域所显现的万象共同构成。物质、概念、时间与生命，凡此种种，皆是织域之上的显相；这些显相构成了人们所认知的现实。

少数生灵能够拨动织域，通过微调或破缺改变显相；这便是这个世界的魔法运作方式。
